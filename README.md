# ระบบจำลองหุ่นยนต์คลังสินค้า (Warehouse Robot Simulation)

## รายละเอียดโครงการ (Project Description)

Warehouse Robot Simulation เป็นโปรแกรมที่พัฒนาด้วยภาษา C++ เพื่อจำลองการทำงานของหุ่นยนต์หลายตัวภายในคลังสินค้า โดยหุ่นยนต์จะเคลื่อนที่บน Grid เพื่อทำงานที่ได้รับมอบหมาย พร้อมจัดการพลังงานแบตเตอรี่และเดินทางกลับไปยังสถานีชาร์จเมื่อแบตเตอรี่เหลือน้อยหรือมีพลังงานไม่เพียงพอสำหรับการทำงาน

ระบบประกอบด้วยหุ่นยนต์ 2 ประเภท ได้แก่ Picker และ Packer ซึ่งสามารถทำงานที่แตกต่างกันตามประเภทของงานที่ได้รับมอบหมาย โดยระบบจะจำลองการทำงานเป็นรอบเวลา (Discrete Timestep) และแสดงสถานะการทำงานของหุ่นยนต์และความคืบหน้าของงานในแต่ละรอบ

## ความสามารถของระบบ (Features)

- **หุ่นยนต์หลายตัว:** รองรับหุ่นยนต์ประเภท Picker และ Packer
- **การจัดการงาน:** รองรับงานประเภท Picking และ Packing
- **การเคลื่อนที่บน Grid:** หุ่นยนต์เคลื่อนที่ครั้งละ 1 ช่องต่อหนึ่งรอบเวลา
- **การมอบหมายงาน:** มอบหมายงานให้หุ่นยนต์ที่สามารถทำงานประเภทนั้นได้
- **การจัดการแบตเตอรี่:** แบตเตอรี่ลดลงเมื่อหุ่นยนต์เคลื่อนที่และทำงาน
- **ระบบชาร์จอัตโนมัติ:** หุ่นยนต์เดินทางกลับไปยังสถานีชาร์จเมื่อแบตเตอรี่เหลือน้อยหรือไม่เพียงพอสำหรับงานถัดไป
- **การแสดงผลการจำลอง:** แสดงแผนผังคลังสินค้า สถานะหุ่นยนต์ และความคืบหน้าของงานในแต่ละรอบเวลา
- **สรุปผลการจำลอง:** แสดงจำนวนรอบเวลาที่ใช้ จำนวนงานที่สำเร็จ และจำนวนงานที่หุ่นยนต์แต่ละตัวทำสำเร็จ
- **โหมดการใช้งาน:** รองรับ Default Mode สำหรับการตั้งค่าเริ่มต้น และ Custom Mode สำหรับกำหนดค่าหุ่นยนต์ งาน และสถานีชาร์จด้วยตนเอง

## เทคโนโลยีที่ใช้ (Technologies)

- ภาษา C++ (C++17)
- การเขียนโปรแกรมเชิงวัตถุ (Object-Oriented Programming: OOP)
- Standard Template Library (STL)
- Vector และ String สำหรับจัดการข้อมูลภายในโปรแกรม

## การออกแบบเชิงวัตถุ (Object-Oriented Programming)

โปรเจกต์นี้นำหลักการ Object-Oriented Programming (OOP) มาใช้ในการออกแบบและพัฒนาโปรแกรม ดังนี้

### 1. Encapsulation (การห่อหุ้มข้อมูล)

ใช้ `private` ในการกำหนดขอบเขตการเข้าถึงข้อมูลภายในคลาส เช่น Robot และ Task เพื่อป้องกันการแก้ไขข้อมูลโดยตรง และใช้ Public Methods ในการเข้าถึงหรือเปลี่ยนแปลงข้อมูล

### 2. Inheritance (การสืบทอดคุณสมบัติ)

ใช้คลาส Robot เป็น Base Class และให้คลาส Picker และ Packer สืบทอดคุณสมบัติจาก Robot เพื่อลดการเขียนโค้ดซ้ำและแยกหน้าที่ของหุ่นยนต์แต่ละประเภท

### 3. Polymorphism (การพ้องรูป)

ใช้ Virtual Functions ในคลาส Robot เช่น `work()` และ `getType()` เพื่อให้คลาส Picker และ Packer สามารถกำหนดพฤติกรรมการทำงานของตนเองได้ โดยเรียกใช้งานผ่าน Base Class ได้

### 4. Composition (การประกอบกันของวัตถุ)

คลาส Warehouse ทำหน้าที่จัดการและรวบรวมวัตถุ Robot และ Task ไว้ภายใน เพื่อควบคุมการทำงานของหุ่นยนต์และการมอบหมายงานภายในคลังสินค้า

### 5. Constructor และ Destructor

ใช้ Constructor สำหรับกำหนดค่าเริ่มต้นให้กับวัตถุเมื่อสร้างขึ้น และใช้ Destructor สำหรับจัดการทรัพยากรเมื่อวัตถุถูกทำลาย

## วิธีติดตั้งและเรียกใช้งาน (How to Compile and Run)

ติดตั้ง Compiler สำหรับภาษา C++ เช่น g++ และตรวจสอบให้รองรับมาตรฐาน C++17 ก่อนเริ่มใช้งาน

### 1. Compile โปรแกรมหลัก

เปิด Terminal ในโฟลเดอร์โปรเจกต์ แล้วใช้คำสั่ง:

```bash
g++ -std=c++17 -Iinclude src/*.cpp -o warehouse.exe
```

### 2. เริ่มต้นโปรแกรมจำลอง

สำหรับ Windows ใช้คำสั่ง:

```powershell
.\warehouse.exe
```

## การทดสอบโปรแกรม (Unit Testing)

โปรเจกต์มีการทดสอบการทำงานแยกตามคลาส ได้แก่ Robot และ Task โดยใช้ `assert` เพื่อตรวจสอบผลลัพธ์ของการทำงาน

### 1. Robot Unit Test

Compile:

```bash
g++ -std=c++17 -Iinclude tests/robot_test.cpp src/Robot.cpp src/Picker.cpp -o robot_test.exe
```

Run:

```powershell
.\robot_test.exe
```

### 2. Task Unit Test

Compile:

```bash
g++ -std=c++17 -Iinclude tests/task_test.cpp src/Task.cpp -o task_test.exe
```

Run:

```powershell
.\task_test.exe
```
