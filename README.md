# Warehouse Robot Simulation
## โปรแกรมจำลองการทำงานของหุ่นยนต์ในคลังสินค้า

โปรเจกต์นี้เป็นโปรแกรมจำลองการทำงานของหุ่นยนต์ภายในคลังสินค้า พัฒนาด้วยภาษา C++ โดยประยุกต์ใช้หลักการเขียนโปรแกรมเชิงวัตถุ (Object-Oriented Programming: OOP) เพื่อจำลองการเคลื่อนที่ การมอบหมายงาน การทำงาน และการจัดการพลังงานแบตเตอรี่ของหุ่นยนต์หลายตัว

---

## 1. ภาพรวมของโครงการ

Warehouse Robot Simulation เป็นโปรแกรมจำลองการทำงานของหุ่นยนต์ภายในพื้นที่คลังสินค้า โดยใช้พื้นที่จำลองแบบตาราง (Grid) ขนาด 10 × 5 ช่อง

ภายในระบบประกอบด้วยหุ่นยนต์หลายประเภท ซึ่งแต่ละตัวมีชื่อ ประเภท ตำแหน่ง สถานะการทำงาน และระดับพลังงานแบตเตอรี่เป็นของตนเอง

ระบบใช้การจำลองแบบ Discrete Timestep โดยหุ่นยนต์สามารถเคลื่อนที่ได้ครั้งละ 1 ช่องต่อหนึ่ง Timestep และเมื่อเดินทางถึงตำแหน่งที่ได้รับมอบหมาย จะเริ่มปฏิบัติงานตามระยะเวลาที่กำหนด

นอกจากนี้ยังมีระบบจัดการพลังงานแบตเตอรี่อัตโนมัติ เมื่อหุ่นยนต์มีพลังงานต่ำหรือมีพลังงานไม่เพียงพอสำหรับการทำงานและเดินทางกลับสถานีชาร์จ ระบบจะสั่งให้หุ่นยนต์เดินทางกลับไปชาร์จพลังงานก่อนกลับมาทำงานต่อ

## 2. วัตถุประสงค์ของโครงการ

1. เพื่อพัฒนาโปรแกรมจำลองการทำงานของหุ่นยนต์ภายในคลังสินค้า
2. เพื่อประยุกต์ใช้หลักการเขียนโปรแกรมเชิงวัตถุด้วยภาษา C++
3. เพื่อจำลองการเคลื่อนที่และการมอบหมายงานให้กับหุ่นยนต์
4. เพื่อจัดการพลังงานแบตเตอรี่และการชาร์จพลังงานของหุ่นยนต์
5. เพื่อฝึกการออกแบบและแบ่งการทำงานของโปรแกรมออกเป็นคลาสต่าง ๆ
6. เพื่อทดสอบการทำงานของโปรแกรมด้วย Unit Testing

## 3. ความสามารถของระบบ

ระบบมีความสามารถหลักดังนี้

- รองรับหุ่นยนต์หลายตัวและหุ่นยนต์หลายประเภท
- มอบหมายงานให้หุ่นยนต์ตามประเภทของงาน
- จำลองการเคลื่อนที่บนพื้นที่แบบ Grid
- หุ่นยนต์เคลื่อนที่ครั้งละ 1 ช่องต่อหนึ่ง Timestep
- จำลองการทำงานตามระยะเวลาที่กำหนด
- จัดการระดับพลังงานแบตเตอรี่ของหุ่นยนต์
- ส่งหุ่นยนต์กลับไปยังสถานีชาร์จโดยอัตโนมัติ
- แสดงตำแหน่งและสถานะของหุ่นยนต์
- แสดงความคืบหน้าของงาน
- สรุปผลการจำลองเมื่อสิ้นสุดการทำงาน

## 4. รายละเอียดการจำลอง

### 4.1 พื้นที่คลังสินค้า

| รายการ | รายละเอียด |
|---|---|
| ความกว้าง | 10 ช่อง |
| ความสูง | 5 ช่อง |
| พิกัด X | 0–9 |
| พิกัด Y | 0–4 |
| รูปแบบการจำลอง | Discrete Timestep |

### 4.2 ประเภทของหุ่นยนต์

| ประเภทหุ่นยนต์ | หน้าที่ |
|---|---|
| Picker | รับผิดชอบงาน Picking |
| Packer | รับผิดชอบงาน Packing |

### 4.3 ประเภทของงาน

| ประเภทงาน | ระยะเวลาทำงาน |
|---|---:|
| Picking | 2 Timestep |
| Packing | 3 Timestep |

### 4.4 ระบบจัดการแบตเตอรี่

| การทำงาน | การเปลี่ยนแปลงแบตเตอรี่ |
|---|---:|
| เคลื่อนที่ 1 ช่อง | ลดลง 1% |
| ทำงาน 1 Timestep | ลดลง 2% |
| ชาร์จแบตเตอรี่ 1 Timestep | เพิ่มขึ้น 20% |

เงื่อนไขการจัดการแบตเตอรี่

- แบตเตอรี่มีความจุสูงสุด 100%
- เมื่อแบตเตอรี่ต่ำกว่า 20% จะถือว่าเป็นสถานะแบตเตอรี่ต่ำ
- ระบบตรวจสอบพลังงานที่ต้องใช้ในการเดินทางไปยังงาน การทำงาน และการเดินทางกลับสถานีชาร์จ
- หากพลังงานไม่เพียงพอ หุ่นยนต์จะเดินทางกลับสถานีชาร์จ
- เมื่อแบตเตอรี่เต็ม 100% หุ่นยนต์จะกลับไปทำงานที่ได้รับมอบหมายต่อ
- หากแบตเตอรี่ไม่เพียงพอสำหรับการเดินทางไปยังสถานีชาร์จ ระบบจะหยุดการจำลองและแจ้งเตือนความผิดพลาด

## 5. รูปแบบการใช้งานโปรแกรม

### 5.1 รูปแบบการกำหนดค่า

**Default Mode**

เป็นการใช้ค่าการจำลองที่กำหนดไว้ล่วงหน้า ประกอบด้วย

- หุ่นยนต์ 3 ตัว
- งานทั้งหมด 5 งาน
- สถานีชาร์จอยู่ที่พิกัด (9, 4)

**Custom Mode**

ผู้ใช้สามารถกำหนดค่าการจำลองได้ด้วยตนเอง ได้แก่

- ตำแหน่งสถานีชาร์จ
- จำนวนหุ่นยนต์
- ประเภทและชื่อของหุ่นยนต์
- ตำแหน่งเริ่มต้นของหุ่นยนต์
- ระดับแบตเตอรี่เริ่มต้น
- จำนวนงาน
- ประเภทและชื่องาน
- ตำแหน่งปลายทางของงาน
