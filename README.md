# Warehouse Robot Simulation
## โปรแกรมจำลองการทำงานของหุ่นยนต์ในคลังสินค้า

โปรเจกต์นี้เป็นโปรแกรมจำลองการทำงานของหุ่นยนต์ภายในคลังสินค้า พัฒนาด้วยภาษา C++ โดยประยุกต์ใช้หลักการเขียนโปรแกรมเชิงวัตถุ (Object-Oriented Programming: OOP) เพื่อจำลองการเคลื่อนที่ การมอบหมายงาน การทำงาน และการจัดการพลังงานแบตเตอรี่ของหุ่นยนต์หลายตัว

---

## 1. ภาพรวมของโครงการ

Warehouse Robot Simulation เป็นโปรแกรมจำลองการทำงานของหุ่นยนต์ภายในพื้นที่คลังสินค้า โดยใช้พื้นที่จำลองแบบตาราง (Grid) ขนาด 10 × 5 ช่อง

ภายในระบบประกอบด้วยหุ่นยนต์หลายประเภท ซึ่งแต่ละตัวมีชื่อ ประเภท ตำแหน่ง สถานะการทำงาน และระดับพลังงานแบตเตอรี่เป็นของตนเอง

ระบบใช้การจำลองแบบ Discrete Timestep โดยหุ่นยนต์สามารถเคลื่อนที่ได้ครั้งละ 1 ช่องต่อหนึ่ง Timestep และเมื่อเดินทางถึงตำแหน่งที่ได้รับมอบหมาย จะเริ่มปฏิบัติงานตามระยะเวลาที่กำหนด

นอกจากนี้ยังมีระบบจัดการพลังงานแบตเตอรี่อัตโนมัติ เมื่อหุ่นยนต์มีพลังงานต่ำหรือมีพลังงานไม่เพียงพอสำหรับการทำงานและเดินทางกลับสถานีชาร์จ ระบบจะสั่งให้หุ่นยนต์เดินทางกลับไปชาร์จพลังงานก่อนกลับมาทำงานต่อ

## 2. วัตถุประสงค์ของโครงการ

1. เพื่อพัฒนาโปรแกรมจำลองการทำงานของหุ่นยนต์ภายในคลังสินค้า
2. เพื่อประยุกต์ใช้หลักการเขียนโปรแกรมเชิงวัตถุด้วยภาษา C++
3. เพื่อจำลองการเคลื่อนที่และการมอบหมายงานให้กับหุ่นยนต์
4. เพื่อจัดการพลังงานแบตเตอรี่และการชาร์จพลังงานของหุ่นยนต์
5. เพื่อฝึกการออกแบบและแบ่งการทำงานของโปรแกรมออกเป็นคลาสต่าง ๆ
6. เพื่อทดสอบการทำงานของโปรแกรมด้วย Unit Testing

## 3. ความสามารถของระบบ

ระบบมีความสามารถหลักดังนี้

- รองรับหุ่นยนต์หลายตัวและหุ่นยนต์หลายประเภท
- มอบหมายงานให้หุ่นยนต์ตามประเภทของงาน
- จำลองการเคลื่อนที่บนพื้นที่แบบ Grid
- หุ่นยนต์เคลื่อนที่ครั้งละ 1 ช่องต่อหนึ่ง Timestep
- จำลองการทำงานตามระยะเวลาที่กำหนด
- จัดการระดับพลังงานแบตเตอรี่ของหุ่นยนต์
- ส่งหุ่นยนต์กลับไปยังสถานีชาร์จโดยอัตโนมัติ
- แสดงตำแหน่งและสถานะของหุ่นยนต์
- แสดงความคืบหน้าของงาน
- สรุปผลการจำลองเมื่อสิ้นสุดการทำงาน

## 4. รายละเอียดการจำลอง

### 4.1 พื้นที่คลังสินค้า

| รายการ | รายละเอียด |
|---|---|
| ความกว้าง | 10 ช่อง |
| ความสูง | 5 ช่อง |
| พิกัด X | 0–9 |
| พิกัด Y | 0–4 |
| รูปแบบการจำลอง | Discrete Timestep |

### 4.2 ประเภทของหุ่นยนต์

| ประเภทหุ่นยนต์ | หน้าที่ |
|---|---|
| Picker | รับผิดชอบงาน Picking |
| Packer | รับผิดชอบงาน Packing |

### 4.3 ประเภทของงาน

| ประเภทงาน | ระยะเวลาทำงาน |
|---|---:|
| Picking | 2 Timestep |
| Packing | 3 Timestep |

### 4.4 ระบบจัดการแบตเตอรี่

| การทำงาน | การเปลี่ยนแปลงแบตเตอรี่ |
|---|---:|
| เคลื่อนที่ 1 ช่อง | ลดลง 1% |
| ทำงาน 1 Timestep | ลดลง 2% |
| ชาร์จแบตเตอรี่ 1 Timestep | เพิ่มขึ้น 20% |

เงื่อนไขการจัดการแบตเตอรี่

- แบตเตอรี่มีความจุสูงสุด 100%
- เมื่อแบตเตอรี่ต่ำกว่า 20% จะถือว่าเป็นสถานะแบตเตอรี่ต่ำ
- ระบบตรวจสอบพลังงานที่ต้องใช้ในการเดินทางไปยังงาน การทำงาน และการเดินทางกลับสถานีชาร์จ
- หากพลังงานไม่เพียงพอ หุ่นยนต์จะเดินทางกลับสถานีชาร์จ
- เมื่อแบตเตอรี่เต็ม 100% หุ่นยนต์จะกลับไปทำงานที่ได้รับมอบหมายต่อ
- หากแบตเตอรี่ไม่เพียงพอสำหรับการเดินทางไปยังสถานีชาร์จ ระบบจะหยุดการจำลองและแจ้งเตือนความผิดพลาด

## 5. รูปแบบการใช้งานโปรแกรม

### 5.1 รูปแบบการกำหนดค่า

**Default Mode**

เป็นการใช้ค่าการจำลองที่กำหนดไว้ล่วงหน้า ประกอบด้วย

- หุ่นยนต์ 3 ตัว
- งานทั้งหมด 5 งาน
- สถานีชาร์จอยู่ที่พิกัด (9, 4)

**Custom Mode**

ผู้ใช้สามารถกำหนดค่าการจำลองได้ด้วยตนเอง ได้แก่

- ตำแหน่งสถานีชาร์จ
- จำนวนหุ่นยนต์
- ประเภทและชื่อของหุ่นยนต์
- ตำแหน่งเริ่มต้นของหุ่นยนต์
- ระดับแบตเตอรี่เริ่มต้น
- จำนวนงาน
- ประเภทและชื่องาน
- ตำแหน่งปลายทางของงาน

### 5.2 รูปแบบการแสดงผล

**Full Output**

แสดงรายละเอียดการทำงานของระบบ เช่น

- การเคลื่อนที่ของหุ่นยนต์
- การเริ่มต้นและสิ้นสุดงาน
- การลดลงของแบตเตอรี่
- การกลับไปยังสถานีชาร์จ
- การชาร์จแบตเตอรี่

เหมาะสำหรับการตรวจสอบและติดตามรายละเอียดการทำงานของโปรแกรม

**Animation Mode**

แสดงผลการจำลองแบบต่อเนื่อง โดยล้างหน้าจอและอัปเดตข้อมูลในแต่ละ Timestep ประกอบด้วย

- แผนผังพื้นที่คลังสินค้า
- ตำแหน่งของหุ่นยนต์และงาน
- ความคืบหน้าของงาน
- สถานะและระดับแบตเตอรี่ของหุ่นยนต์

มีการหน่วงเวลาระหว่างแต่ละ Timestep เพื่อให้สามารถสังเกตการเคลื่อนที่ของหุ่นยนต์ได้ง่ายขึ้น

## 6. หลักการเขียนโปรแกรมเชิงวัตถุ (OOP)

โครงการนี้ประยุกต์ใช้หลักการเขียนโปรแกรมเชิงวัตถุ ดังนี้

### 6.1 Encapsulation (การห่อหุ้มข้อมูล)

กำหนด Attribute ภายในคลาสให้เป็น Private เพื่อป้องกันการเข้าถึงข้อมูลโดยตรง เช่น ตำแหน่งของหุ่นยนต์ ระดับแบตเตอรี่ และสถานะการทำงาน โดยใช้ Public Methods ในการเข้าถึงและแก้ไขข้อมูล

### 6.2 Inheritance (การสืบทอดคุณสมบัติ)

ใช้คลาส Robot เป็นคลาสพื้นฐาน (Base Class) และให้คลาส Picker และ Packer สืบทอดคุณสมบัติจาก Robot เพื่อให้สามารถใช้ข้อมูลและฟังก์ชันพื้นฐานร่วมกันได้

### 6.3 Polymorphism (การพ้องรูป)

กำหนดฟังก์ชัน work() และ getType() เป็น Virtual Functions ภายในคลาส Robot จากนั้นให้คลาส Picker และ Packer ทำการ Override ฟังก์ชันดังกล่าว เพื่อให้หุ่นยนต์แต่ละประเภทสามารถแสดงพฤติกรรมที่แตกต่างกันได้

### 6.4 Composition (การประกอบวัตถุ)

คลาส Warehouse ทำหน้าที่จัดการกลุ่มของหุ่นยนต์และงาน โดยเก็บข้อมูล Robot และ Task ไว้ภายในคลาส เพื่อควบคุมการทำงานของระบบจำลองทั้งหมด

### 6.5 Constructor และ Destructor

ใช้ Constructor ในการกำหนดค่าเริ่มต้นให้กับวัตถุเมื่อถูกสร้างขึ้น และใช้ Destructor ในการจัดการเมื่อวัตถุถูกทำลาย รวมถึงการคืนหน่วยความจำของหุ่นยนต์ที่ถูกสร้างขึ้นแบบ Dynamic Allocation

## 8. เครื่องมือและข้อกำหนดในการใช้งาน

- ภาษา C++
- C++ Standard: C++17
- Compiler: g++ (แนะนำ MinGW-w64 สำหรับ Windows)
- ใช้งานผ่าน Terminal หรือ PowerShell

## 9. วิธีติดตั้งและเรียกใช้งาน

เปิด Terminal หรือ PowerShell ภายในโฟลเดอร์หลักของโปรเจกต์

### 9.1 Compile โปรแกรม

```bash
g++ -std=c++17 -Iinclude src/*.cpp -o warehouse.exe
```

### 9.2 Run โปรแกรม

สำหรับ Windows PowerShell ใช้คำสั่ง

```powershell
.\warehouse.exe
```

### 9.3 ขั้นตอนการใช้งาน

1. เลือกรูปแบบการกำหนดค่า Default Mode หรือ Custom Mode
2. หากเลือก Custom Mode ให้กำหนดตำแหน่งสถานีชาร์จ หุ่นยนต์ และงาน
3. ตรวจสอบข้อมูลเริ่มต้นของคลังสินค้า
4. กด Enter เพื่อเริ่มขั้นตอนถัดไป
5. เลือกรูปแบบการแสดงผล Full Output หรือ Animation Mode
6. ติดตามการทำงานของหุ่นยนต์จนกว่าการจำลองจะสิ้นสุด
7. ตรวจสอบผลสรุปการจำลอง

## 10. การทดสอบโปรแกรม (Unit Testing)

โครงการนี้ใช้การทดสอบแบบ Unit Testing โดยใช้คำสั่ง assert ของภาษา C++ เพื่อตรวจสอบการทำงานของคลาส Robot และ Task

### 10.1 Robot Unit Test

คำสั่ง Compile

```bash
g++ -std=c++17 -Iinclude tests/robot_test.cpp src/Robot.cpp src/Picker.cpp -o robot_test.exe
```

คำสั่ง Run

```powershell
.\robot_test.exe
```

กรณีทดสอบประกอบด้วย

1. การเคลื่อนที่ของหุ่นยนต์ (Robot Movement)
2. การชาร์จแบตเตอรี่ (Battery Charging)
3. การจำกัดแบตเตอรี่สูงสุด (Battery Maximum)
4. การตรวจสอบแบตเตอรี่ต่ำ (Low Battery Detection)

### 10.2 Task Unit Test

คำสั่ง Compile

```bash
g++ -std=c++17 -Iinclude tests/task_test.cpp src/Task.cpp -o task_test.exe
```

คำสั่ง Run

```powershell
.\task_test.exe
```

กรณีทดสอบประกอบด้วย

1. ระยะเวลาการทำงาน Picking
2. ระยะเวลาการทำงาน Packing
3. สถานะเริ่มต้นของงาน
4. ความคืบหน้าของงาน
5. การสิ้นสุดงาน

- จำนวนงานที่หุ่นยนต์แต่ละตัวทำสำเร็จ
- สถานะและระดับแบตเตอรี่สุดท้ายของหุ่นยนต์แต่ละตัว
